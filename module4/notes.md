# Module Summary: Git and GitHub Basics

In this module, I learned how to install and configure Git to connect with a GitHub personal repository. 

## Key Learnings & Concepts:
* **Installation & Setup:** Configured Git credentials and established secure communication with GitHub repositories.
* **Core Commands:** Practiced essential Git commands for version control, tracking, and committing changes.
* **Branching & Merging:** Created and managed new branches directly through the command line and successfully merged branch updates back into the `main` branch.
